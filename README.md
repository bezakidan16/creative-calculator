# 🧮 Modern & Creative Calculator

A simple, interactive, and beautifully designed web calculator built using **HTML, CSS, and JavaScript**. 

This project was built as part of an application requirement to demonstrate web development basics, clean UI design, and simple JavaScript logic.

---

## 🌟 Features
* **Modern UI:** Designed with a vibrant dynamic gradient background and dark mode panel.
* **Responsive Layout:** Works smoothly on different screen sizes using CSS Grid.
* **Basic Arithmetic Operations:** Supports addition, subtraction, multiplication, and division.
* **Error Handling:** Gracefully handles invalid mathematical expressions without crashing.
* **Quick Controls:** Includes a backspace (⌫) button and clear (C) function.

---

## 🛠️ Tech Stack
* **HTML5:** Structure and content.
* **CSS3:** Styling, grid layout, and gradient design.
* **JavaScript (ES6):** Logic and functionality.

---

## 🚀 How to Run
1. Download or clone this repository.
2. Open the `index.html` file in any modern web browser.
3. Start calculating!
